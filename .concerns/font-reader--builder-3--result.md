(3) Decisions I took (header comments of src/opentype.h and src/fontlib.h state them): fonts are parsed at registration, so a bad file is refused there with a reason; FontLibrary is an object (a context owns one), not module state; no bundled defaults; a registry change RETIRES the old FaceData/FontMetrics instead of freeing them, so pointers handed out never dangle (memory grows by one parsed font per re-registration); a defect confined to one glyph or to GPOS/MATH does not fail the load (empty box / table ignored, warnings() says so) while damage to head/maxp/hhea/hmtx/cmap/outline tables does; refused outright: .ttc, CFF2, CID-keyed CFF, a best cmap in a format other than 4/6/12; TrueType fonts with a MATH table are minted in GLYPH-ID order (no post names read) — self-consistent, not what the reference would assign, no bundled font exercises it; hostile overlapping tables are bounded by explicit work budgets (constants at the top of opentype.cpp).
