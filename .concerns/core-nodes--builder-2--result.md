DECISIONS TAKEN (rationale is at the top of src/units.h and src/nodes.h; please append to docs/decisions.md, which I do not own):
1. Scaled = int64_t, arithmetic unchecked. Invariant: a dimension in a node is within +-MAX_DIMEN (or RUNNING); whoever accepts dimensions from a host/font establishes it (clamp_dimen() provided). Under it no sum over a 32-bit-indexed list overflows int64, and sums over < 2^22 nodes stay < 2^53 (the hazard-doc condition for (double)a/(double)b == Python int/int). Node constructors do NOT clamp. public-api/para must.
2. Float->Scaled (round_to_scaled, used by sp_from_*, round_to_px): NaN -> 0, +-inf/huge -> +-SCALED_LIMIT = 2^62. Tested against the oracle's `raises`/`beyond_int64` records as policy, not as literal reproduction.
3. py_round = std::nearbyint per D18 (depends on the default FP rounding mode; a host that changes fenv changes layout — stated in the header, not defended against).
4. Exceptions -> IMTYPESET_CONTRACT(cond, "what") in units.h: on violation calls a process-wide handler if one is installed, else IM_ASSERT; always evaluates false so the caller takes a defined way out. The handler exists ONLY so tests can run the after-violation path in debug/asan where IM_ASSERT would abort — otherwise D17's "must not execute UB after the assert" is untestable in exactly the builds that would show it. pack/shipout/linebreak should use it for the goldens' `error <slug>` cases. badness(t<0) -> violation + INF_BAD.
5. Node = one 32-byte trivially copyable tagged value; a list is contiguous Nodes (std::vector<Node> or NodeView). Glue carries its whole spec inline (no spec table). Only BOX and DISC have out-of-line data, in a NodeArena, referenced by 32-bit index (never pointers); box/disc contents are contiguous spans of the arena's nodes. NodeType order is tex.web's so is_discardable is one comparison.
6. DEVIATION FROM D21's WORDING: FontKey is not interned. It is a 64-bit value = 15-bit face id + 48-bit size in sp, self-describing, no table anywhere; equal exactly when the reference's strings would be. style.font_key/parse_font_key are FontKey::make / .face() / .size(). Reason: an intern table needs an owner shared by every arena and every module, and buys nothing a packed value does not. Face ids are the font registry's; tests/core_golden.h's FaceTable assigns the reference's Face enum order (prose 0, prose-bold 1, prose-italic 2, prose-bold-italic 3, code 4, code-bold 5, math 6) — font-reader/fontlib should use the same ids or tests that mix both will need a mapping. If you want interning anyway, say so before pack lands on it.
7. ReplacedChar: every CHAR node has `original` + a replaced flag (replaced_char()); replaced_char(f,c,o) != char_node(f,c) as in the reference. Golden tag `rchar` round-trips.
8. Nesting is bounded at construction: NodeArena refuses a box/disc nested deeper than MAX_NESTING = 1024 (contract violation, stored with no contents), and contents can only name earlier nodes, so trees are acyclic and recursive walkers (ship-out, selection, import, deep_equal) need no depth checks. mathtext's own nesting bound must keep its box depth under 1024.
9. Disc.replace_count is stored as given (int32); linebreak must bound it against the list (hazard 11) — not done here.

FOR DOWNSTREAM (pack, linebreak, shipout, math, para): 
- A Box is in the arena; `arena.add_box(header, contents_view)` copies contents contiguous and returns the BOX node. "Same box, shifted" = add a copy of the Box struct (contents span shared).
